# Switter
Switter - платформа для ведения Standalone блога. Работает на любом веб-сервере.   
Для установки необходимо поместить файлы репозитория в корневую директорию веб-сервера, после чего правильно назначить права доступа.   
Далее необходимо придумать пароль, а так же логин администратора (опционально). Пароль необходимо перевести в хеш. Это можно сделать с помощью команды:   
```bash
php -r "echo password_hash('ваш_пароль', PASSWORD_DEFAULT), PHP_EOL;   
```   
   
Либо при помощи утилиты pass2hash.php. Для того, чтобы воспользоваться ей, после разворачивания сервера перейдите: https://yourserver.com/pass2hash.php   
После чего введите и подтвердите пароль, а затем нажмите <Сгенерировать хеш> и скопируйте его.   
Далее откройте admin.php и вставьте хеш вместо ВСТАВЬТЕ_ХЕШ_СЮДА. Так же вы можете изменить admin на другой логин.   
После настройки учётной записи, откройте index.php и задайте название блога и описание. Для этого замените Standelone blog на ваше название и Description на описание соответственно. Кроме того вы можете добавить дополнительную информацию, урбав 
```php
<!-- Здесь вы можете добавить шапку блога (Опционально) Для этого удалите комментарий 
```
и 
```php
-->
```
  
а так же заполнив шапку блога.
   
pass2hash.php не нужен для работы Switter. После настройки сервера вы можете его удалить.


Каталоги uploads/ и archive/ существуют. Приложение может создать uploads/ при открытии панели администратора, но для корректной работы архивации каталог archive/ должен быть доступен для записи.   
   
При архивации записи сохраняются в HTML-файл внутри archive/, изображения копируются в archive/uploads/, а текущий список записей и файлы из uploads/ очищаются.   
   
##  Форматирование записей

Поддерживаются следующие маркеры:   
 * Формат	Синтаксис   
 * Жирный	**текст**   
 * Курсив	*текст*   
 * Подчёркнутый	__текст__   
 * Зачёркнутый	~~текст~~   
 * Ссылка	[название](https://example.com)   

Обычные URL с http:// или https:// также преобразуются в ссылки.
Структура проекта:   

*    index.php — публичная страница блога и поиск.
*    admin.php — вход и панель управления.
*    posts.json — данные опубликованных записей.
*    uploads/ — загруженные изображения.
*    archive/ — HTML-архивы публикаций и архивные изображения.
*    styles.css — стили сайта
   
   
   
## Android клиент
Для данной платформы выпущен [Android клиент](https://github.com/one-loner/Switter_Android), который позволяет публиковать, удалаять и архивировать посты, а также подписываться на другие блоги на данной платформе.
